How to Merge and Split PDF Files

You often need to join a scan and a form into one file, or send only a few pages of a long document. Doing it in the browser means you do not have to send private documents to a website.

Steps

  1. Merge. Add the PDF files, put them in order and download one combined file.
  2. Split. Choose pages such as 1-3,7, split into single pages, or cut the file into parts of a set size.
  3. Organize. Rotate pages, move them, or delete the ones you do not need, then save the result.
  4. Check the result. Open the new file and look at the page count and order before you send it.

Good to know

Large files use your device memory, so a very big PDF on an old phone can be slow.

A merged PDF keeps the properties of the first file in some programs. If that matters, clear the metadata afterwards.

Password-protected PDFs must be unlocked in another program first.
