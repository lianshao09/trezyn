How to Hide a Message in a Picture

Steganography means hiding that a message exists at all. A locked message is clearly a secret. A normal-looking picture is not. The tool hides an encrypted message in the least significant bits of a PNG, changes you cannot see.

Steps

  1. Choose a picture. Use a PNG photo with lots of detail and noise. A flat graphic or a picture with a plain sky gives a statistical tool more to notice. JPG and WebP are converted to PNG first.
  2. Type the message or pick a file. The tool shows how much the picture can hold. Keep it well under the recommended size.
  3. Set a password and press Hide. The data is locked with AES-256-GCM before it is hidden, then spread over pseudo-random positions in the picture. The tool reads it back to check.
  4. Send the PNG as a file. The other person opens it in the Read tab and enters the password.

Open the picture hiding tool

Good to know

It only works while the file stays exactly the same. Sending it as a photo in a messenger, taking a screenshot, resizing or saving as JPG destroys the hidden data. Use email attachments, a cloud folder or "send as file".

It is not invisible to experts. Statistical tests can sometimes show that a picture was altered, especially when a large share of it is used. Hiding makes a secret less obvious, but the password protection is what keeps the content safe. Never use the same picture twice.

If the password is wrong or the picture changed, the tool says only "nothing found", so nobody can tell which it was.
