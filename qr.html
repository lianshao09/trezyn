    About the QR code generator and reader

    Type a web address, Wi-Fi details or any text and the QR code updates as you type. You can change the foreground and background colors, the size from 128 to 1024 pixels, and the error correction level, then save the result as a PNG image.

    Higher error correction levels (Q and H) keep the code readable even if part of it is covered or damaged, but they make the code denser. For printed codes, keep strong contrast between the two colors and leave a clear margin around the code.

    The Read tab decodes a QR code from a picture, a pasted screenshot or the camera, and checks the link before you open it. It warns about link shorteners, look-alike letters, plain http, numeric addresses and a hidden username before an @ sign, which are common tricks in fake QR codes.

    Everything happens inside your browser. The text you enter and the pictures you read are never sent anywhere.
