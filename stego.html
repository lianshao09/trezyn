About hiding data in pictures

Steganography hides the fact that a message exists. This tool changes the lowest bit of some color values in a PNG, a change too small to see, and stores your message there. The message is first locked with AES-256-GCM using a key made from your password, and it is spread over pseudo-random positions in the picture, so without the password there is nothing readable to find.

It works only while the file stays exactly as it is. Messengers, social networks, screenshots, resizing or saving as JPG destroy the hidden data, so send the PNG as a file. Statistical tools can sometimes tell that a picture was changed, especially when a lot of data is hidden, so keep messages short and use a noisy photo.

Nothing is uploaded. The picture is read and written by code in your browser, which also removes the picture metadata, such as location and camera.
