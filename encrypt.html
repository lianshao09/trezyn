About the encryption tool

Type a password and lock a message, or drop in any file. The result can only be opened with the same password. Locked text is a short string you can paste into an email or note. Locked files are saved with the extension .tzenc.

The tool uses AES-256-GCM, the standard used by banks and governments, with a key made from your password by PBKDF2-SHA256 and a new random salt every time. If the password is wrong or the data was changed, unlocking fails instead of giving wrong output.

There is no password recovery. If you forget it, the data is gone. Use a long password or a passphrase, and keep it in a password manager. Nothing is uploaded: the locking happens in your browser and needs a secure (https) connection.
